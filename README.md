# 🏆 E-Government Healthcare Services — UI/UX Design

A mobile healthcare application designed to provide citizens with easy access to essential government healthcare services.

This project achieved **🥇 1st Place in the AAU UI/UX Competition 2026**.

## 🎨 Interactive Prototype

👉 [View the Interactive Prototype on Figma](https://www.figma.com/proto/A68qjDbTQN7S1AUyYDiRaG/e-government-healthcare-services-design?node-id=13-2&starting-point-node-id=13%3A2)

## 📱 Project Overview

The application provides a centralized and user-friendly interface for accessing healthcare services, allowing users to manage their health information and interact with medical services through one mobile application.

### Key Features

- 🩺 Book medical appointments
- 💊 Access prescriptions
- 🧪 View laboratory results
- 📋 Access personal health records
- 💉 Track vaccinations
- ⚠️ View important allergy alerts
- 🏥 Find nearby clinics
- 👨‍👩‍👧 Manage family healthcare information
- 🪪 Access insurance information
